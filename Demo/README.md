# Demo Notebooks

This folder contains some **executed** notebooks that demonstrate how the pipeline
works end-to-end. They are meant as a **quick reference** to show what the
outputs look like and to guide new users through the workflow.

> **Note.** These notebooks are **real runs from the experiments**. The datasets used here are exactly the same as those
> provided in [`../datasets/`](https://github.com/Persian-NLP-Research/Persian-Sentiment-LLM-Augmentation/tree/main/datasets), but only the **file names** differ
> from the names used in the paper. The mapping is given below:

| File name in notebook | Name in paper        |
|------------------------|----------------------|
| `originalDS1000`     | Original(+1000)     |
| `originalDS1146`     | Original(+1146)     |
| `originalDSCG`       | Original(+1646)    |
| `balancedDSCG`       | Balanced(+1646)    |
| `translationDSCG`    | Translation(+1646)  |
