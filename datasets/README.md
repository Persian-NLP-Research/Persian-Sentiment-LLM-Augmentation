This folder contains the datasets used in our experiments, together with a small script to audit their intrinsic quality. See Section 3 of the paper for dataset construction details.

> **Note.** The test set is a separate, fixed file shared across **all**
> experiments. It is never modified or regenerated.

## Source

The baseline datasets are derived from the **SentiPers** corpus and its
**DeepSentiPers** processed release:

- **SentiPers (original corpus):** https://github.com/phosseini/SentiPers
- **DeepSentiPers (processed dataset):** https://github.com/JoyeBright/DeepSentiPers/tree/master/Dataset

Please refer to these repositories for details. The data was normalized and lightly cleaned before use. The version stored in this repository is the post-preprocessing version used in all experiments. The augmented set was generated on top of this baseline using LLM-based data augmentation (see the paper for details).


## Augmentation Prompt

The augmented training samples were generated by prompting **DeepSeek-V3-0324** and **GPT-4o mini** through their public web interfaces, one source sentence at a time, using the prompt below. The placeholder `<برچسب>` (Persian prompt) / `<label>` (English translation) was replaced by the source sentence's true label (∈ {-2, -1, 0, 1, 2}) and `<جمله>` (Persian) / `<sentence>` (English) by the sentence itself.

### Original prompt (Persian)


"برای تسک طبقه‌بندی پنج‌کلاسه، با لیبل‌های -2 (خیلی منفی) تا +2 (خیلی مثبت)، قصد داریم با تولید جملات جدید از روی نمونه‌های برچسب‌دار موجود، به تقویت داده یا همان data augmentation بپردازیم. به عنوان یک متخصص در حوزه تولید متن فارسی با در نظر گرفتن احساس، جمله زیر را که دارای برچسب احساس `<برچسب>`
 است را بخوان و پنج جمله فارسی جدید با حفظ شدت احساس و لیبلش در همان حوزه مربوط به جمله تولید کن، درحالیکه ضمن حفظ انسجام و کیفیت زبان طبیعی، قطبیت و شدت آن نیز حفظ شود:

`<جمله>`"

### English translation (for reference only)

"For a five-class sentiment classification task with labels ranging from –2 (strongly negative) to +2 (strongly positive), we aim to perform data augmentation by generating new sentences from existing labeled samples. As an expert in sentiment-aware Persian text generation, read the following sentence, which has a sentiment label of `<label>`, and generate 5 new Persian sentences in the same domain that preserve both the sentiment polarity and its intensity, while maintaining coherence and natural language quality:

`<sentence>`"

## Quality Audit

`audit_dataset.py` reports intrinsic quality and diversity statistics for a given CSV, exact-duplicate rate, near-duplicate rates at Jaccard thresholds `0.70` and `0.80`, mean pairwise Jaccard distance, and lexical diversity (TTR / Distinct-1, Distinct-2).
